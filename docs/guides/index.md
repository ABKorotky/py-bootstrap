# Guides

Task-focused recipes. Each assumes `ak-py-bootstrap` is {doc}`installed
<../installation>`.

- {doc}`generate-a-project` — scaffold an application or a package.
- {doc}`write-a-bootstrap` — create a new bootstrap from scratch.
- {doc}`export-and-modify-a-bootstrap` — start from a copy of an existing one.
- {doc}`register-a-bootstrap` — make a local bootstrap available to the tool.
- {doc}`distribute-bootstraps-as-a-plugin` — ship bootstraps inside your own package.
